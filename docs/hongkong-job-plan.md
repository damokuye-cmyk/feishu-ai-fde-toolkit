## 一、甲方 vs 乙方：你的转型优势

### 你的独特卖点：10 年甲方 + 6 年乙方

大多数候选人是纯甲方或纯乙方。你是少有的「两边都干过」的人。

```
2009-2019   中国电信湖北           甲方  ★★★★★
            企业信息化部·产品总监
            (BSS/CRM/ERP/计费系统)
            管 4 家厂商 60+ 人

2019-2021   华为(数据分析)          混合  ★★★
            数据挖掘/ML模型/5G

2021-2026   华为云(沙特)           乙方  ★★★★★
            高级解决方案架构师
            AI Agent / 云迁移 / 金融架构
```

### 这个组合在面试中的杀伤力

```
面试官问: "你怎么管理供应商？"
纯甲方的人: "我们定期 review SLA..."
你: "我在电信管过 4 家厂商 60 人，知道他们怎么报工期、
    怎么藏风险。后来我去华为云做了乙方，
    现在我既知道供应商怎么想的，也知道怎么管他们。"
                                  ↑ 这就是你的碾压点
```

### 你的叙事升级版

```
不是 "我从乙方转型去甲方"
而是 "我两边都干过，知道怎么让两边高效合作"
```

### 乙方出身 → 甲方受欢迎的原因

```
你在华为云做乙方时积累的:
  ┌─────────────────────────────────────────┐
  │ 看过几十家企业怎么上云、怎么踩坑          │
  │ 知道供应商的底价、套路、能力边界          │
  │ 有 CIO/CXO 级对话能力                    │
  │ 主导过百万美金级的项目交付                │
  └─────────────────────────────────────────┘
  
甲方 HR 看到的是:
  ┌─────────────────────────────────────────┐
  │ 这个人不会被供应商忽悠                    │
  │ 他能管好云预算和供应商                    │
  │ 他懂业务也懂技术，能跟CEO讲清楚          │
  │ 他能把技术和业务目标对齐                  │
  └─────────────────────────────────────────┘
```

## 五、薪资对标 & 生活成本

### 三地对比

```
             香港 HKD          新加坡 SGD          马来西亚 MYR
薪资范围    150~220 万        20~35 万           35~70 万
折合 RMB    140~205 万        110~195 万         55~110 万
税率顶部    15% (200万约23万)  22% (200万约44万)   30% (200万约60万)
租房(月)    2.5~3.5 万        3~5 千 SGD         3~5 千 MYR
饮食(月)    0.8~1.2 万        0.8~1.2 千 SGD     1.5~2.5 千 MYR
语言环境    粤语+英语+普通话    英语为主+华语       马来语+英语+华语
```

### 实际到手对比（年薪170万HKD等价）

```
                   香港(HKD)        新加坡(SGD)      马来西亚(MYR)
名义薪资           170 万           30 万            50 万
≈ RMB             158 万           168 万           78 万
个税               ~20 万           ~5.4 万          ~11 万
社保/CPF           ~2 万            6 万(CPF)        ~4.5 万
实际到手           ~148 万          18.6 万          ~34.5 万
≈ RMB             ~138 万          ~104 万          ~54 万
```

> 香港税负最低，同样名义薪资到手最多。新加坡的 CPF 雇主缴 17% 相当于额外福利，但个人缴 20% 短期现金流少。

## 八、面试准备（甲方侧重点）

### 甲方面试 vs 乙方面试的区别

```
乙方面试                          甲方面试
─────────                       ─────────
"你怎么设计这个方案？"             "你怎么判断该选哪个方案？"
"你怎么搞定客户？"                 "你怎么管理供应商？"
"你怎么推动项目交付？"             "你怎么衡量技术投入的ROI？"
"你用什么技术？"                   "你为什么选这个技术，别的为什么不行？"
"你带过多大的团队？"               "你怎么管理预算和人？"
```

### 甲方必问题准备

```
1. "如果我们上多云，你怎么帮我们决策？"
   → 你的经验: 华为云+AWS+Azure 三家的踩坑经验 → 直接给建议

2. "你怎么评估云支出是否合理？"
   → 你在华为云看过几十家客户的账单 → FinOps 框架

3. "AI 投入很大，你怎么说服董事会？"
   → AI 推理中心的 ROI 模型 → 先 PoC 再规模化

4. "你怎么选 AI 平台？商业版 vs 开源？"
   → Langgraph/LiteLLM vs 商业平台 → 按场景决策

5. "你管过最大的团队和预算？"
   → 沙特项目 20+ 人跨职能团队 + 百万美金预算
```

## 九、优先级建议

```
🇭🇰 香港  ——— 最优选
  ├── 税低, 到手多
  ├── 离家近 (华南区)
  ├── 中英双语环境, 你的优势最大
  └── 银行/金融甲方多, 最匹配你的金融经验

🇸🇬 新加坡 ——— 备选1
  ├── 薪资水平高, 国际化程度最高
  ├── 竞争激烈 (全球人才都在那)
  ├── 生活成本极高 (房租跟香港差不多)
  └── 需要额外办 EP (Employment Pass)

🇲🇾 马来西亚 ——— 备选2
  ├── 生活成本低 (HK 1/3)
  ├── 薪资天花板低 (70万 MYR ≈ 110万 RMB 已是顶级)
  ├── Petronas 等大型国企可能匹配
  └── 华人多, 语言适应快
```

**建议策略：** 主攻香港甲方 (投 15~20 家)，同步投新加坡 (5~8 家) 做备选，马来作为兜底选项。
